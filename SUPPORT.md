# Support

- **Questions and discussion:** [Discord](https://wilds.ai/discord). GitHub issues are for bugs and feature requests.
- **Documentation:** [docs.wunderland.sh](https://docs.wunderland.sh) and the guides in [docs/](https://github.com/jddunn/wunderland/tree/master/docs)
- **Bugs and feature requests:** the [issue forms](https://github.com/jddunn/wunderland/issues/new/choose). Search the existing issues first. A bug in the AgentOS runtime belongs in [agentos](https://github.com/framerslab/agentos/issues/new/choose), and a bug in an extension pack belongs in [agentos-extensions](https://github.com/framerslab/agentos-extensions/issues/new/choose).
- **Security issues:** report privately as the [security policy](https://github.com/jddunn/wunderland/blob/master/.github/SECURITY.md) describes, never in a public issue.
- **Commercial, partnership or sponsorship inquiries:** team@frame.dev

To contribute, see [CONTRIBUTING.md](https://github.com/jddunn/wunderland/blob/master/CONTRIBUTING.md).
